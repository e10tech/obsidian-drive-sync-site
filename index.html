Obsidian Drive Sync

A personal desktop utility for synchronizing Obsidian notes with Google Drive.

About

Obsidian Drive Sync is a personal-use project designed to synchronize selected Obsidian vault files between a Windows computer and Google Drive.

The project is under development and is not offered as a public synchronization service.

Google Drive Access

The application uses Google OAuth 2.0 and the Google Drive API. Access is requested only for the synchronization features authorized by the user.

The application uses the Google Drive file access scope to manage files created or selected for use with the application.
