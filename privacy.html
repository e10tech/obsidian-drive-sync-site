Privacy Policy

Last updated: November 16, 2026

1. Purpose

Obsidian Drive Sync is a personal-use desktop application designed to synchronize selected Obsidian files with Google Drive.

2. Google User Data

The application uses Google OAuth 2.0 and the Google Drive API. It requests the drive.file permission to access and manage files created or selected for use with the application.

3. Use of Data

Google Drive file data is used solely for the synchronization functions requested by the user, including file comparison, uploading, downloading, and conflict detection.

4. Storage and Sharing

The application is designed to run on the user's own computer. OAuth credentials and synchronization data are stored locally or in the user's own Google Drive account as appropriate.

The application does not sell Google user data or share it with advertisers. No separate developer-operated cloud service is used to collect synchronized note contents.

5. Data Retention and Deletion

Local files and authentication credentials remain under the user's control. The user can delete local application data and revoke Google account access through Google Account settings.

6. Security

The application is designed to use OAuth authentication and Google's official Drive API. Access credentials must not be published in the website repository.

7. Website Hosting

This informational website is hosted on GitHub Pages. GitHub may process visitor information under its own privacy policies. The website does not intentionally use analytics or advertising trackers.

8. Changes

This policy may be updated when the application's features or data handling practices change.
